# 📊 Unemployment Analysis Dashboard

An interactive data analytics project focused on analyzing unemployment patterns in India using **Python, Pandas, Excel, and Microsoft Power BI**.

The project combines data preprocessing, Python-based analysis, and an interactive Power BI dashboard to explore unemployment across different states, districts, demographic groups, education levels, employment statuses, and COVID-19 phases.

---

## 📌 Project Overview

The **Unemployment Analysis Dashboard** is designed to transform unemployment data into meaningful and interactive visual insights.

The project uses Python for data processing and analysis and Power BI for creating an interactive dashboard.

The analysis covers the period **2020–2026** and focuses on understanding unemployment patterns across different geographical and demographic dimensions.

---

## 🎯 Project Objectives

- Analyze unemployment patterns across different states and districts.
- Compare unemployment based on gender.
- Analyze unemployment according to education level.
- Understand employment status distribution.
- Analyze unemployment trends across different COVID-19 phases.
- Perform data preprocessing and transformation using Python.
- Create an interactive dashboard using Power BI.
- Generate meaningful insights from unemployment data.
